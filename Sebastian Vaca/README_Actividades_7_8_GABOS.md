# README — Actividades 7 y 8 | GABO'S IHC

## Actividad 7. Proponer la validación

Para validar el prototipo de gestión de citas de **GABO'S Readaptación y Movimiento**, se definió un protocolo de prueba orientado a usuarios representativos.

Las tareas propuestas para la validación son:

1. Encontrar un horario disponible.
2. Registrar una cita.
3. Cambiar la fecha o el fisioterapeuta.
4. Cancelar una cita.
5. Volver a agendar después de una cancelación.

Durante cada tarea se deben registrar los siguientes indicadores:

- Éxito de la tarea.
- Tiempo empleado.
- Número de acciones realizadas.
- Necesidad de intervención o ayuda.
- Errores cometidos.

### Comprobación técnica realizada

Antes de ejecutar pruebas con participantes reales, se realizó una revisión técnica del prototipo para comprobar su funcionamiento frente a los requisitos de la rúbrica.

Se verificó lo siguiente:

- Pantalla de inicio y acceso a las acciones principales.
- Consulta de disponibilidad.
- Selección de fisioterapeutas.
- Registro de datos del paciente.
- Resumen previo a la confirmación.
- Generación de código de cita.
- Consulta y detalle de una cita.
- Navegación hacia atrás sin perder la información ingresada.
- Horarios ocupados identificados y deshabilitados.
- Confirmación antes de cancelar una cita.
- Reagendamiento de una cita.
- Retroalimentación visual mediante estados y mensajes.
- Etiquetas visibles y estados que no dependen únicamente del color.
- Controles con foco para navegación mediante teclado.

La tabla de participantes **P1, P2 y P3** se mantiene preparada para registrar resultados reales. No se inventaron tiempos, porcentajes de éxito, satisfacción ni otros resultados que no hayan sido observados directamente.

## Actividad 8. Emitir una recomendación

Después de analizar el proceso actual, comparar las alternativas de agendamiento y revisar el prototipo, se seleccionó el **mecanismo híbrido** como la alternativa más adecuada para GABO'S.

### Razones de la selección

El mecanismo híbrido permite:

- Reducir el trabajo administrativo repetitivo.
- Disminuir la coordinación manual mediante WhatsApp y agenda física.
- Mejorar la visibilidad del estado de las citas.
- Prevenir conflictos de horarios.
- Permitir que los casos normales se gestionen de manera más automática.
- Mantener intervención administrativa para casos especiales o excepciones.
- Adaptarse al funcionamiento de un centro con cinco fisioterapeutas.

La recomendación no se basa únicamente en una preferencia personal, sino en la comparación de mecanismos, los problemas detectados en el flujo **AS-IS**, los criterios de eficiencia, la factibilidad técnica y la coherencia con los principios de HCI.

### Recomendación final

Se recomienda implementar el **mecanismo híbrido de gestión de citas**, ya que ofrece un equilibrio entre automatización y control humano. Este enfoque ayuda a reducir errores, tiempos de coordinación y tareas repetitivas, sin eliminar la intervención del personal cuando sea necesaria.

Antes de una implementación real, se recomienda completar la validación con usuarios representativos y registrar los resultados de las tareas definidas en la Actividad 7.
